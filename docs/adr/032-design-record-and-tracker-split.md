# 032 design-record-and-tracker-split
epic: none · pr: none

## Decisions
- @process @rfc @adr @issues — Three artifacts with three jobs: a proposal under review lives in `docs/rfcs/` and changes by pull request; a decision already made lives in `docs/adr/` and is append-only; execution lives in the issue tracker and closes. REJECTED: one artifact carrying all three, with the design in the issue body — an issue has no diff, so a design that shifts mid-flight leaves a comment thread and a silently-rewritten description, and the tracker's own job competes for attention with a document nobody can review.
- @process @rfc @merge-state — An RFC merges to the default branch early, in `Draft`, and advances by editing a status field; merging is not acceptance. REJECTED: gating the merge on agreement — it hides the proposal on a branch during the exact window when it most needs readers, and the detached worktree threads that later implement it read from the default branch, so an unmerged design is invisible to the machinery that consumes it.
- @process @issues @decomposition — One tracking issue per proposal, holding a link and a checklist; the decomposition and its dependency edges live in the RFC. REJECTED: pre-cutting one issue per unit of work with tier labels encoding DAG position — every unit then exists before any work starts, none was ever *found*, and the tracker becomes a work-breakdown structure that can only be executed or abandoned, never argued with as a whole.
- @process @adr @grouping — ADR files group decisions by subject sharing a rate of change, not one file per task and not one file per decision. REJECTED: one file per task — a volatile area's churn forces reopening settled decisions filed beside it, and this corpus has areas that turned over three times against areas that never moved. REJECTED: one file per decision — the directory becomes unreadable, and tag-addressed supersession is already finer than a filename.
- @process @adr @append-only — A decision's text is never rewritten: supersession moves the bullet verbatim into a `## Superseded` section with a pointer to its successor, and file status is derived from structure (an empty `## Decisions` section means superseded). REJECTED: a declared status field — a second source of truth that can disagree with the file's contents, and one more thing to forget to update.
- @process @adr @admission — A decision earns a record only if all three hold: hard to reverse, unintuitive, and a genuine trade-off with a real rejected alternative. REJECTED: recording every choice — a template that demands a decisions section on every unit of work reliably produces decisions, and roughly half of what one produced here restated the code or had already been reversed by later work.
- @process @lanes @refactor — A refactor is direct-lane only when it stays inside one module boundary and the code it touches already has tests; moving a seam, changing a public interface, or touching untested code makes it design-lane. REJECTED: treating refactors as mechanical by default — "behavior-preserving" without coverage means *hoped* to be preserving, and one frontend structure was migrated six successive times because the shape was never argued, each pass superseding the last.
- @process @hooks @distribution — Git hooks live in a tracked directory selected by `core.hooksPath`, not in the untracked default hooks directory. REJECTED: the default location — it works immediately and then vanishes on the next clone, is invisible to review, and gives a contributor no check at all. The per-clone enabling command is the accepted cost, and switching the path silently disables anything left in the default directory, so existing hooks migrate first.

## Takeaway
- takeaway: every artifact in a process has a rate of change, and co-locating two that differ makes the stable one hostage to the volatile one. That single rule decided the proposal-versus-record split, the ADR file grouping, and where a decomposition lives — and where it was ignored, the symptom was always the same: re-deciding something that was already settled, because nobody could find the argument that settled it.
