# 095 granular-language-change-suspension
epic: none · pr: none

## Decisions
- @suspense @i18n @skeleton — a database list or detail page shows its page-level skeleton only while its spec loads; a language change may swap localized text for name-sized skeletons and never the page. Whether a page honours this is a property of the render tree, which Suspense boundary the first language-keyed suspense query lands under, so the guard is a render test: it enumerates the exported router's database routes, mounts each page, flips the language, and asserts that no element marked `data-slot="page-skeleton"` appears, and it fails on a route missing from its own page table. All detail fallbacks render through `DetailPageSkeleton` and all list fallbacks through `ListPageSkeleton`, so the marker sits on those two components alone. REJECTED: per-page "does not suspend" tests — the ones that existed mocked the hook synchronously and could never go red; the theme pack shell drifted with a comment on it claiming the opposite. REJECTED: an ast-grep rule on i18n hook calls in page files — the keyword detail page reads i18n hooks inside its page file under internal boundaries, correctly, and a file-scoped rule flags it. REJECTED: a hand-kept page list in the test — a page added by someone who never read the test is the drift being fenced; enumerating the router makes registration a test failure instead of a convention.
- @staticData @hooks @split — a hook over static entity data returns either the language-independent spec or the language-keyed text, never both: `use…ListSpec` / `use…ListI18n` and `use…DetailSpec` / `use…DetailI18n`, with the combined `useEntityListData`, `useEntityDetailData`, every per-slice `use…ListData` / `use…DetailData`, and `useStartBuffData` deleted, the last becoming `useStartBuffListSpec` / `useStartBuffListI18n` with the merge in a pure `toStartBuffs`. Both pages that drifted reached for the combined hook and every page that stayed granular called the split spec hook, so the combined shape is the footgun. An ast-grep rule rejects defining or calling any hook matching `^use\w+(List|Detail)Data$`. REJECTED: keeping the combined hook for leaves that want both — two calls cost one line and suspend identically, and keeping the shape keeps the trap for the next shell. REJECTED: banning the `Data` suffix outright — server-backed hooks such as `useMDGesellschaftData` share it and have nothing to split; the `(List|Detail)Data` suffix has no collateral. REJECTED: a rule on what a hook does rather than what it is named — "a hook issuing a language-keyed suspense query returns nothing else" is not expressible in ast-grep, so the start buff rename keeps the fence a single regex rather than an allowlist.
- @themePack @card — `ThemePackCard` takes an id and renders its own name under a name-sized boundary, matching `EGOGiftCard`; callers no longer pass a name. Corollary of the split: the list must not suspend on names, so the card owns the boundary and the list reads search terms through `useSearchTermSources`.

## Takeaway
- takeaway: a convention lives in a comment and lasts until the next reader; an invariant lives where violating it fails loudly. When the property is a tree shape, the only honest guard is a render test with a registration point a new case cannot skip, and a lint rule is at most the fence that removes the shape people reach for.
