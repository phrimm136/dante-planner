# 033 account-bootstrap-stacks
epic: none · pr: none · supersedes: 003 @terraform @state @bootstrap

## Decisions
- @terraform @state @bootstrap @accounts — the state bucket is created by `state-backend`, applied once per account, and the provisioning identity by `iam-bootstrap`, applied only to accounts that run the fleet. Both keep local state, for the same circularity reason as before. Every account needs a bucket, but only a fleet account needs a role granting EC2, RDS, autoscaling, ECR, SSM and KMS, and that role carries no `count`, so no input suppresses it. One bundled stack therefore mints a fleet-shaped role inside an account whose only purpose is holding audit records the other accounts must not be able to reach. REJECTED: keeping the bundle and deleting the surplus role by hand — nothing re-asserts a manual deletion, so the next apply restores it. REJECTED: leaving a member account with no bucket and keeping its stack on local state — defensible where the account holds one resource, has no cross-stack reads, no concurrent applies and no secrets in state, but an environment account fails all four, so the split arrives regardless and rehearsing it on an account that holds nothing is the cheaper order.
- @terraform @state @migration — an existing bucket stays in the stack that created it; only accounts created afterwards use `state-backend`. Relocating a `prevent_destroy` resource across state files is surgery on the object holding every stack's state, and it buys nothing until that account is rebuilt. REJECTED: relocating it for consistency — the account concerned is scheduled to be rebuilt as a member account, and its bucket is created there by the new stack when it is, so the inconsistency expires on its own.

## Takeaway
- takeaway: two resources bundled into one stack share an assumption about how many of each will exist, and nobody writes that assumption down because at the time both counts are one. It survives until the counts diverge, and then the bundle starts installing the resource nobody asked for wherever the other one is needed.
