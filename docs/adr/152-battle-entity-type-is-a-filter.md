# 152 battle-entity-type-is-a-filter
epic: none · pr: none · supersedes: 117 @scope @sprite @reset @facets @slice

## Decisions
- @battle @type — Within the selected mode, the entity type (enemy, assist unit, event sinner) is a multi-select filter in the filter panel, empty meaning all, so one list can show enemies and assist units together; the mode stays the single-select top row. Supersedes ADR 117 @scope's single-select type row and @reset's type clause: reset clears the type filter with the other filters. REJECTED: a single-select type row above the list — the type is one more way to narrow what a mode fields, and a mutually exclusive row hides that a mode's assist units and enemies fight together.
- @battle @sprite — A card draws its sprite at 45 px per world unit with the skill-slot anchor 35 % below the sprite box top, cropping what falls outside. Supersedes ADR 117 @sprite's 53 px and 15 %. REJECTED: 53 px with the anchor at 15 % — humanoids sat at the card's top edge and mid-size abnormalities were cut; REJECTED: feet at the bottom edge — every tall unit loses its head, which is where the skill slots sit.
- @battle @rows — Engagement rows whose label and content match (same unit, level, generated parts and shown stage-effect keywords) collapse into one selector entry; rows whose labels match but whose content differs take a positional suffix "(1)", "(2)" in row order. The game names no finer place for them: 11,004 of 12,286 same-label Mirror Dungeon pairs, all 93 Walpurgis pairs and 258 of 284 story-dungeon pairs are content-identical, and duplicated node titles leave the rest without a name. REJECTED: a companion-enemy hint in the label — longer labels that still need a suffix when the roster matches; REJECTED: showing every stage row — identical entries offer a choice that changes nothing.

- @battle @facets — Within a mode, the stage drill-downs (chapter, theme pack or event, line, dungeon) and the name search narrow every entity type alike, because the drill-down keys are properties of the stages a type's rows engage, and assist units and event sinners engage stages as enemies do; Luxcavation stays a mode of its own. REJECTED: name search only for assist units and event sinners — a merged list cannot apply a facet to some cards and not others.
- @battle @slice — The catalog is one `battle` slice with one entity section per family, discovered one directory deeper as `battle/<family>`, and one list whose facet table is shared by the three sections; a page may not import another page's list. REJECTED: one slice per family — the merged list would import three slices.
  INVARIANT: every family in the battle vocabulary has its entity section — the entity-section guard.

## Takeaway
- takeaway: an axis that narrows a list is a filter even when it partitions the data; a partition only earns its own exclusive control when mixing the parts would mislead.
